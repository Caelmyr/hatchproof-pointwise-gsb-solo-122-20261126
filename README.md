# HatchProof · 排线试片台

在画稿正拍照片上设一个原图框，比较当前横截线和全框的可见排线方向。只在源点有实际左右上下像素邻证时求方向。先用两对原像素测中心亮差，再将纹理方向转90°得到笔向；0°为水平，角度180°循环，同一轴两头视为同一方向。纹理强度低于阈值时保原值但不计笔向。显示五度箱的真实计数。

可使用注明为合成的练习或导入单帧 PNG、JPEG、TIFF、BMP、WebP。保留原片点读、保存重开、原值 CSV、PNG 校样、含原照的 ZIP，以及发送原照到照片准备。

`docker compose up --build` 后打开 `http://127.0.0.1:19925/`。服务只监听本机，卡和准备工程存于命名卷。
