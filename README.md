# HatchProof · 排线试片台

在画稿正拍照片上设一个原图框，沿当前截线找两组各有实拍邻点支撑的笔向，也保留全框的可见排线分布。只在源点中心与左右上下邻点都在原框内、且任一 RGB 通道不触 0 或 255 时算作原点。先用两对原像素测中心亮差，再将纹理方向转90°得到笔向；0°为水平，角度180°循环，同一轴两头视为同一方向，179° 与 1° 只差 2°。纹理强度低于阈值时保原值但不计笔向。每组至少四个不同原点，组内每点与本组轴向之差都在所填容差内，两组轴向至少相差25°；同一点只归一组。有多组合格配对时先取真实支持点更多的，再取两组内部方向更齐的。界面按这两种笔向分辨原点，点读任一源点会显示其实际归组或未采用的原因，并保留原角度、强度与 RGB。显示五度箱的真实计数。

可使用注明为合成的练习或导入单帧 PNG、JPEG、TIFF、BMP、WebP。保留原片点读、保存重开、原值 CSV、PNG 校样、含原照的 ZIP，以及发送原照到照片准备。

`docker compose up --build` 后打开 `http://127.0.0.1:19925/`。服务只监听本机，卡和准备工程存于命名卷。
