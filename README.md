# HatchProof · 排线试片台

在画稿正拍照片上设一个原图框，比较当前横截线和全框的可见排线方向。只在源点有实际左右上下像素邻证时求方向。先用两对原像素测中心亮差，再将纹理方向转90°得到笔向；0°为水平，角度180°循环，同一轴两头视为同一方向。纹理强度低于阈值时保原值但不计笔向。显示五度箱的真实计数。

可使用注明为合成的练习或导入单帧 PNG、JPEG、TIFF、BMP、WebP。保留原片点读、保存重开、原值 CSV、PNG 校样、含原照的 ZIP，以及发送原照到照片准备。

## 单笔笔宽

在原片选择“量笔宽”，点一个墨内原点并填写笔向、沿笔最远距离和黑墨亮度上限。服务只沿原点两侧第一段连续可见墨线寻找候选横切，遇到第一处非墨像素即停止，不会跨过暗线中断接到另一笔。每道横切沿笔向法线读取真实原像素和去重后的连续墨段；墨段两端外的第一点必须是框内、未缺失、任一 RGB 通道都不是 0/255，且亮于对应墨端的纸点。笔宽按两个实际墨端像素中心在单位法线上的投影距离加 1 px。多道可量时，结果按近原点和两端最小墨纸反差综合排序，并返回全部候选。

采用候选后，“截线证据”图切换为该斜截的真实原像素亮度/RGB 轨迹；点击图表或墨端按钮会复用原片点读显示两个真墨端。原有水平截线的方向读数和全框方向统计保持不变。接口为 `GET/POST /hatchproof/cards/<id>/width`，支持 `x`、`y`、`angle`（或 `direction`）、`reach`（或 `max_distance`）、`ink_limit`（或 `ink_threshold`）。

`docker compose up --build` 后打开 `http://127.0.0.1:19925/`。服务只监听本机，卡和准备工程存于命名卷。
